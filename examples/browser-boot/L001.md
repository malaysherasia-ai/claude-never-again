# L001 — a syntax checker cannot see a TDZ error

**Filed:** 2026-09-12 · **Scope:** web · **Form:** hook (block)

## Symptom

Every button on the page was dead. Tabs, header strip, the lot — nothing
responded to a click. No visible error, no failed request.

## Cause

A `let` declaration was used by a function that ran before the declaration was
reached. That is a temporal dead zone ReferenceError, and it aborts the whole
script at boot, so every event listener registered after it silently never
attached.

`node --check` passed. It only parses. The error is a runtime one.

## Rule

Boot every build in a real browser before shipping. A syntax check is not a
boot.

## Why this became a hook

The check is mechanical and takes one sentence: *before committing, fail if the
page was not loaded headlessly since the last edit.* Nothing about it needs
judgement, so leaving it as a note in `LESSONS.md` would have been paying
tokens forever for something a script can hold.

## The line in LESSONS.md

```
- [web] [hook] Boot the build in a real browser, not `node --check` — when: before commit (L001)
```
