Mistakes that can't repeat.

never-again is a Claude Code skill that turns every bug you fix into a guardrail. Enforceable lessons become hooks that deny the wrong action. The rest become one line the agent reads each turn. Nothing phones home.

$git clone --depth 1 https://github.com/malaysherasia-ai/claude-never-again.git && bash claude-never-again/install.sh

works on macos, linux, wsl // python 3 // no accounts, no telemetry

// how it works

One question per bug.

Can a script catch this before it happens? If yes, it becomes a hook: it runs before every commit, from Claude Code and from git itself, and costs one line to carry. If no, it becomes a rule line — capped per file, ordered by what fires most, scoped per package, because compliance falls as the list grows.
