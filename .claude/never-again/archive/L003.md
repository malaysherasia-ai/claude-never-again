# L003: evidence for a check must change for that reason only

**Filed:** 2026-09-21, while releasing 1.6.0. Form: rule line.

**Symptom.** The capture check stayed silent on a fix commit in the test
whenever the test had just flipped a setting in `state.json`.

**Cause.** The check took a changed `state.json` as proof that a lesson
was being filed, because the skill writes a lesson record there. But
`state.json` also changes for a setting, a registered agent, a promotion.
Any such edit left uncommitted would have silenced the check for every
fix after it, on the agent's side, where "changed" means the whole
working tree.

**Rule.** When a check looks for a side effect as evidence that something
happened, the evidence must be a file that changes for that reason and no
other. Here: the archive entry, the rule line, or a hook script. Not the
index that everything writes to.

**Fix.** `state.json` was dropped from the list in `_capture.sh`; the
skill text says the same.

**What would have gone red:** nothing. The test caught it by accident,
through its own edits to the file. A judgement rule.
