## Lessons

Read `LESSONS.md` before writing or changing code. If a package you are working
in has its own `LESSONS.md`, read that one too. These are rules earned from real
bugs in this repo — treat them as binding, not advisory.

When a bug is fixed, a test is repaired, or the user corrects you, invoke the
`never-again` skill to capture it. Do not write to `LESSONS.md` by hand.
